# Peaxy

> Peaxy, Inc. is a San Jose, California industrial AI and digital-twin software company founded in 2012, with offices in Stockholm, Sweden and Cagliari, Italy. Its Peaxy Lifecycle Intelligence (PLI) platform threads design, test, manufacturing, field and service data for mission-critical physical assets into a single cloud-based source of truth, then applies machine learning to predict failures, extend asset life and support warranty, quality and readiness decisions.

Generated by the API Evangelist enrichment pipeline on 2026-08-26 because Peaxy serves no llms.txt of

not a document Peaxy published.

## API status

Peaxy states on several product pages that "We provide a range of open API's that allow for the most
flexible implementations that grow as you do" (/build/, /innovate/, /lims/, /battery-analytics/).
As of 2026-08-26 that API has no public surface: no developer portal, no API reference, no OpenAPI,
AsyncAPI, GraphQL SDL, Postman collection, MCP server or A2A agent card could be found on any Peaxy
host. Access runs through a demo request and a customer engagement. An agent cannot call Peaxy today.

The peaxy.net marketing site is WordPress and therefore answers /wp-json/ with the WordPress core REST
API (467 routes across wp/v2, yoast/v1, contact-form-7/v1, google-site-kit/v1 and similar plugin
namespaces). That is the CMS behind the website, not the PLI product API, and it is deliberately not
catalogued as a Peaxy API contract.

## Note for agents

Do not attempt to call a Peaxy API. No base URL, authentication scheme, operation or error contract is
published anywhere public as of 2026-08-26. The correct action for an agent asked to integrate with
Peaxy is to surface https://peaxy.net/request-live-demo/ to a human.
